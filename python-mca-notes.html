Unit 1: Computational Thinking & Algorithmic Logic

1.1 Introduction to Programming and Computational Thinking

Programming means giving a set of instructions to a computer so that it can perform a task. A computer cannot think on its own; it follows the instructions carefully.

Examples:
- Add two numbers
- Search data in a file
- Arrange marks in order
- Create monthly bill calculations

Computational thinking means solving a problem in a structured and logical way. It helps us think like a programmer.

  • Decomposition: Break a big problem into smaller parts
  • Pattern Recognition: Find similar repeated parts
  • Abstraction: Focus only on important details
  • Algorithm Design: Create step-by-step solution

Problem Analysis

Before writing code, we must understand the problem clearly.

  1. Read the problem carefully
  2. Identify input and output
  3. Understand the conditions and rules
  4. Find the logic
  5. Write steps and code
Example: Find the largest of three numbers.
Input: a, b, c
Process: compare values
Output: largest value

Algorithm Design

An algorithm is a step-by-step procedure to solve a problem.

Characteristics of a good algorithm:

  • Clear and understandable
  • Finite number of steps
  • Precise and unambiguous
  • Produces correct output
Algorithm to add two numbers: 1. Start 2. Read a and b 3. Calculate sum = a + b 4. Display sum 5. Stop

Flowcharts

A flowchart is a graphical representation of an algorithm. It uses symbols to show steps and decisions.

Common flowchart symbols:

  • Oval: Start/Stop
  • Rectangle: Process
  • Parallelogram: Input/Output
  • Diamond: Decision
  • Arrow: Flow direction
Start ↓ Read num ↓ Is num % 2 == 0? ├── Yes → Print "Even" └── No → Print "Odd" ↓ Stop

Pseudocode

Pseudocode is a simple, English-like description of logic.

BEGIN READ a, b, c IF a > b THEN IF a > c THEN PRINT a ELSE PRINT c ENDIF ELSE IF b > c THEN PRINT b ELSE PRINT c ENDIF ENDIF END

Tracing / Dry Run

Dry run means running the logic manually, line by line, to check the output.

a = 5 b = 7 c = a + b print(c)

Dry run:

  1. a = 5
  2. b = 7
  3. c = 12
  4. print(c)

Output: 12

Unit 2: Python Control Flow, Functions & Modules

2.1 Conditional Statements and Loops

if statement

age = 18 if age >= 18: print("Adult")

if-else

num = 5 if num % 2 == 0: print("Even") else: print("Odd")

if-elif-else

marks = 75 if marks >= 90: grade = "A" elif marks >= 75: grade = "B" elif marks >= 60: grade = "C" else: grade = "D" print(grade)

for Loop

Used when the number of iterations is known.

for i in range(1, 6): print(i)

while Loop

Used when the number of iterations depends on a condition.

i = 1 while i <= 5: print(i) i += 1

break, continue, pass

for i in range(1, 10): if i == 5: break print(i) for i in range(1, 6): if i == 3: continue print(i) for i in range(5): pass
  • break: stop the loop
  • continue: skip current iteration
  • pass: do nothing

2.2 Functions

A function is a reusable block of code. It helps to organize programs.

def add(a, b): return a + b print(add(3, 4))

Parameters and Arguments

def greet(name): print("Hello", name) greet("Aman")

Return Values

def square(n): return n * n result = square(5) print(result) # 25

Scope of Variables

x = 10 # global variable def show(): y = 20 # local variable print(x) print(y) show()

Global variables are accessible throughout the program, whereas local variables work inside a function only.

Lambda Functions

Lambda functions are short anonymous functions.

square = lambda x: x * x print(square(4))

Recursion

A recursive function calls itself.

def factorial(n): if n == 0 or n == 1: return 1 return n * factorial(n - 1) print(factorial(5))

Important points:

  • Base case must exist
  • Function must move toward base case
  • It can be elegant but careful with infinite recursion
